# วิชางานไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้น 20100-1005 (ปวช.) ฉบับเรียงตามหนังสือเรียน

สื่อการสอนแบบเว็บ (static site) สำหรับ GitHub Pages แยกโฟลเดอร์ตามบทของหนังสือเรียน (`ch02/` = บทเรียนที่ 2)
เว็บเดิมที่เรียงตามแผนการสอนอยู่ที่ `../Basic-Electrical-Electronics-slides/` (w01–w04)

- `index.html` หน้าแรก
- `chNN/slides.html` สไลด์ (← → / Space, T = สารบัญ, F = เต็มจอ) มุมขวาบนบอกหน้าหนังสือ
- `chNN/quiz.html` แบบทดสอบก่อน/หลังเรียน = แบบฝึกหัดท้ายบทตอนที่ 1 ในหนังสือ
- `chNN/exercises.html` แบบฝึกหัด (ตรวจทันที, พิมพ์ใบงาน A4) + ตอนที่ 2 ของหนังสือแบบเขียนตอบ
- `chNN/answers.html` เฉลยสำหรับครู (ต้องใส่รหัสครู) รวมแนวคำตอบใบปฏิบัติงาน
- `ch02/meters.js` ภาพมัลติมิเตอร์ หน้าปัด วงจรการต่อวัด จอสโคป และเครื่องฝึกอ่านเข็ม (วาดใหม่ทั้งหมด)

## แก้เฉลย / เปลี่ยนรหัสครู
1. แก้ `_private/answers-ch02.json`
2. รัน `node _private/encrypt-answers.mjs ch02 "รหัสครู"` จากโฟลเดอร์นี้ (ต้องมี Node.js 18 ขึ้นไป)
3. อัปโหลด `ch02/answers.enc.js` และ `ch02/check-data.js` ใหม่

`_private/` และ `บทเรียน/` (รูปถ่ายหนังสือ มีลิขสิทธิ์) อยู่ใน `.gitignore` ห้ามอัปขึ้น GitHub
